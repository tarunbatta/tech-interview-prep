# Git Workflow & Commit Guidelines

## Automatic Commit Message Generation

- Whenever completing any code, documentation, script, or configuration modifications in the repository, ALWAYS conclude your response with ready-to-use git commit message recommendations.
- Provide two choices:
  1. **Option 1: One-Liner (Conventional Commit)**: Compact `<type>(<scope>): <summary>` format.
  2. **Option 2: Detailed Multi-Line Commit**: Summary line followed by bullet points detailing specific changes, rationale, and validation status.
- Follow Conventional Commits conventions with accurate types (`feat`, `fix`, `docs`, `refactor`, `chore`, `test`) and relevant scopes (`(system-design)`, `(core)`, `(practice)`, `(docs)`, etc.).
